Noregstoget — Live Norwegian Train Map

Noregstoget er eit skjematisk kart over det norske jernbanenettet som viser togposisjonar i sanntid. Kartet er utforma som eit rørbanenett-kart (London Tube-stil) og dekkjer alle norske passasjertogruter.

Noregstoget is a schematic, tube-map-style visualization of Norway's passenger rail network. It displays live train positions updated every 15 seconds, using data from Entur's public APIs.

Kva kartet viser / What the map shows

  • 26 norske passasjertoglinjer / 26 Norwegian passenger rail lines
  • Omtrent 280 stasjonar / Approximately 280 stations
  • Sanntids togposisjonar oppdatert kvart 15. sekund / Real-time train positions updated every 15 seconds
  • Avgangstavler og ankomsttavler per stasjon / Departure and arrival boards per station
  • Ruteinfo og forseinkingar per tog / Route details and delays per train

Operatørar / Operators

  • Vy (VYG) — largest national operator; Bergensbanen, commuter lines, Østfoldbanen
  • SJ Nord (SJN) — long-distance northern routes; Nordlandsbanen, Dovrebanen, Rørosbanen
  • Go Ahead Nordic (GOA) — Sørlandsbanen, Vestfoldbanen, Jærbanen
  • Gjøvikbanen AS (GJB) — Oslo–Gjøvik commuter service
  • FlixTrain (FLT) — budget intercity

Datakjelder / Data Sources

  • Entur GTFS-RT vehicle positions: https://api.entur.io/realtime/v1/gtfs-rt/vehicle-positions
  • Entur SIRI-VM fallback: https://api.entur.io/realtime/v1/rest/vm
  • Entur Journey Planner GraphQL: https://api.entur.io/journey-planner/v3/graphql

Alle Entur-API-ar er opne og gratis (ingen API-nøkkel krevst). / All Entur APIs are open, free, and require no API key.

Slik brukar du kartet / How to use

  1. Opne https://togkartet.msge.no i nettlesaren din / Open https://togkartet.msge.no in your browser
  2. Tog vises som fargekoda prikkar på kartet / Trains appear as colour-coded dots on the map
  3. Klikk på eit tog for å sjå rute, stasjonar og forseinkingsinformasjon / Click a train to see its route, stops and delay info
  4. Klikk på ein stasjon for å sjå avgangstavle / Click a station to see the departure board
  5. Kartet oppdaterer seg automatisk kvart 15. sekund / The map refreshes automatically every 15 seconds

Teknisk / Technical

Vanilla JavaScript SPA (ingen rammeverk / no framework). Leaflet.js for kartvisning / map rendering. Protocol Buffers (protobuf.js) for GTFS-RT-dekoding / GTFS-RT decoding. Hosta på GitHub Pages / Hosted on GitHub Pages. Kildekode / Source: https://github.com/mmsge/togkartet
